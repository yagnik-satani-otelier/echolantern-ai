# Changelog

## 1.0.0 - 2026-10-27

- Initial EchoLantern keepsake maker for the Hacktoberfest Week 4 theme.
- Added local Gemma 3 1B generation via Ollama with explicit JSON-schema output and transparent template fallback.
- Added memory capture for people, places, pets, family stories, everyday memories, and meaningful objects/traditions.
- Added editable keepsake, reflective paragraph, inscription, and follow-up question fields.
- Added local archive, search, photo attachment with browser-side compression, Markdown download, delete, and JSON backup export.
- Added static-host fallback for Vercel previews, responsive styling, PWA shell caching, privacy notes, test coverage, and submission/demo drafts.
