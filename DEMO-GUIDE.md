# EchoLantern demo guide (60–90 seconds)

Use fictional or non-sensitive example memories. Do not record a private family story without permission.

1. Open EchoLantern and show the local-first / privacy note.
2. Use the sample memory or enter a short note about a rainy-day kitchen, a favorite place, a pet, or another memory you are comfortable sharing.
3. Optionally attach a photo and show that the preview is local to the page.
4. Click **Light the lantern**. For a local AI demo, show the `LOCAL AI` badge and explain that Gemma runs through Ollama on the same machine. If it says `TEMPLATE MODE`, describe it as the fallback rather than AI output.
5. Briefly inspect the keepsake, micro-story, inscription, and question. Mention that the text is editable and the source note remains the factual anchor.
6. Save it to the lantern and open Memory Archive.
7. Download a Markdown copy or export the JSON backup.
8. If showing Vercel, be explicit that it demonstrates the interface and template fallback; it cannot connect to the local Ollama process.

Do not claim that the app contacts spirits, verifies memories, or guarantees the absence of model hallucinations. Explain that generated text needs human review.
